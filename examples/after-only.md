# 改寫後的正文（lint 夾具）

這個檔案把 `before-after.md` 裡 8 組「改寫」段落原樣摘出來，用來跑機械檢查：

```bash
python scripts/ste-lint-zh.py examples/after-only.md
```

期望：硬違規 0（建議類可能有個別命中，比如第 8 組保留了「被鎖記錄」）。

本工具同步各個已設定後端的狀態。如果發現衝突，本工具讀取已設定的策略。策略允許自動處理時，本工具直接處理衝突。策略不允許時，本工具把衝突交給人工複核。

您的請求可能已失敗。原因可能是資料格式與伺服器期望的格式不一致。用戶端版本過舊會造成這種不一致。請檢查用戶端版本。

讀取設定檔。解析設定。必要時調整設定項目。把結果寫入日誌。

任務已完成，產物可讀。全部輸出檔案已寫入 `dist/`。

重構快取層：把淘汰邏輯從 LRU 換成帶過期時間的 LRU，讀寫路徑的重複程式碼合併到 `CacheStore`。本機基準測試：命中快取時讀取耗時從 1.8 ms 降到 0.9 ms。順帶修了 2 個 bug：過期項不回收、空鍵傳回舊值。

這個程式庫把建置、測試、部署三步合成一條命令：`dev up`。使用預設設定，一條命令可以啟動本機環境（Node 20+，首次約 40 秒）。
